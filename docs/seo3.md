# Business Goals (Client)

## Primary Goal

Generate **4--8 new qualified personal injury cases per month** from
organic Google search.

## Success Metric

**Signed cases**, not: - Traffic - Clicks - Impressions - Phone calls
alone

The objective is to attract **qualified, not-at-fault injury victims**
who become paying clients.

------------------------------------------------------------------------

# Ideal Client Profile

-   Injured in an accident
-   Not at fault
-   Located in Las Vegas or surrounding areas
-   Needs medical treatment
-   Has an insurance claim
-   High-value settlement potential

# Technical SEO Standards

Every important page should include:

-   Optimized Title Tag
-   Optimized Meta Description
-   Single H1
-   Proper H2/H3 hierarchy
-   Internal links
-   FAQ section
-   Image ALT text
-   Canonical URL
-   Structured Data

Required Schema:

-   LegalService
-   Attorney
-   Organization
-   FAQ
-   Breadcrumb

Also maintain:

-   XML Sitemap
-   robots.txt
-   Core Web Vitals
-   Mobile-first design

# Development Guardrails

-   Never optimize for services the firm does not offer.
-   Prioritize client revenue over search volume.
-   Preserve URLs whenever possible.
-   Avoid duplicate titles and metadata.
-   One primary keyword per page.
-   Every page should have a clear CTA.
-   Every page should strengthen topical authority in Personal Injury.
-   Do not chase random keywords.
